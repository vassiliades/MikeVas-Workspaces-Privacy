# MikeVas Workspaces Privacy Policy

**Effective date: September 25, 2026**

MikeVas Workspaces is a local-first browser extension for saving and restoring browser workspaces.

## Data handled by the extension

To provide its workspace features, the extension handles the following information from tabs selected by the user:

- page titles and URLs;
- tab order and pinned state;
- browser tab group names, colors, order, and collapsed state;
- workspace names, colors, and local revision information.

This information is used only to create, display, update, synchronize, and restore the user's browser workspaces.

## Storage and synchronization

Workspace information is stored locally in the user's browser profile. If the user installs the optional Sync Helper and manually selects a `workspaces.json` file, the extension can read or write that file when the user presses **Sync now**. The selected file may be located in a folder synchronized by a storage provider chosen and controlled by the user.

The developer does not operate a server that receives workspace information. The extension does not automatically transmit workspace information to the developer or to third parties.

## Data sharing and sale

MikeVas Workspaces does not sell user data. It does not use or transfer user data for advertising, creditworthiness, lending, or purposes unrelated to the extension's single purpose. It does not share workspace information with the developer or third parties.

## Website content

The extension does not inspect or collect the body content of web pages. It handles the title and URL shown by the browser only as needed to save and restore selected tabs.

## Data retention and deletion

Workspace information remains in the browser profile until the user deletes the workspace, clears the extension's storage, removes the browser profile, or uninstalls the extension. Files created through manual synchronization remain under the user's control and can be deleted by the user at any time.

## Limited Use

The use of information received from browser APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

Material changes to this policy will be published on this page with a revised effective date.

## Contact

Privacy or support questions can be submitted through the publisher contact information shown in the browser extension store listing.
